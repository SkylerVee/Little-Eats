# Little Eats: Fine Kenyan Dining & Culinary Experience

A modern, high-performance web application designed for an Afro-fusion fine-dining restaurant. **Little Eats** combines elegant visual design with practical online utility, offering interactive ordering, serverless table reservations, dynamic multi-currency payment processing, and responsive cross-device performance.

## Features

- **Hero Section:** High-definition background video with overlay navigation.
- **Sticky Navigation Bar:** Fixed header with dynamic backdrop blur for effortless section jumps.
- **Interactive Signature Carousel:** Horizontal card slider with smooth scroll control buttons.
- **Visual Menu & Cart:** Dynamic dish catalog categorized by meats, stews, Swahili specialties, drinks, and desserts.
- **PayPal Smart Payments:** Automatic client-side currency conversion (KES to USD) using the PayPal JavaScript SDK.
- **Serverless Table Reservations:** Contact form processing routed directly to email via Formspree.
- **Responsive Architecture:** Customized CSS grid and flexbox breakpoints optimized for mobile, tablet, and desktop viewports.

## Tech Stack

- **Frontend:** HTML5, CSS3, Modern JavaScript (ES6+)
- **Icons:** Font Awesome 6
- **Payment Gateway:** PayPal SDK (Dynamic USD conversion)
- **Form Handling:** Formspree API
- **Deployment & Hosting:** Vercel & GitHub Pages
